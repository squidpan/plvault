# Project requirements workspace

Store project requirement notes under:

`Notes/pjs/<project>/docs/reqs/`

Use these optional child folders to keep artifacts navigable:

- `epics/`
- `features/`
- `stories/`
- `acceptance-criteria/`
- `canvases/`

Relationships are expressed through stable YAML IDs rather than file paths.
The Requirements Base and Canvas generator both use this project-root
convention.
