## Summary

Welcome to the Excalidraw Essentials Mini Course! In our first lesson, we dive right into the basics. You will discover three distinct methods to create a new Excalidraw drawing within Obsidian. Having multiple ways to create a canvas gives you the flexibility to build a workflow that fits your unique needs perfectly, whether you’re working directly inside an existing markdown document or navigating your vault.

![](https://www.youtube.com/watch?v=p8HvcOxMHP4)

- [01:57](https://www.youtube.com/watch?v=p8HvcOxMHP4&t=117s) - Method 3: Converting a placeholder Markdown file into a drawing

## Key Takeaways

- **Command Palette:** From within any markdown document, use `Ctrl/Cmd + P` and select “Create Embed New Drawing” to seamlessly link a new canvas.
- **Ribbon Icon:** `Ctrl/Cmd + Click` the Excalidraw ribbon icon on the side panel to instantly open a new drawing in a new tab.
- **Markdown Conversion:** You can create a link to a non-existent file (`[[My Drawing]]`), click to create it as a standard markdown file, and then use the Command Palette to convert it into a fully functional Excalidraw drawing.
