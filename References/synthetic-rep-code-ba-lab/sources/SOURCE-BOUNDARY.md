# Source Boundary

This repository may contain only:

- Publicly available, appropriately summarized domain concepts
- Generic BA methods and templates
- Fully fictional systems, identifiers, data, requirements, and examples
- Sanitized lessons that cannot reconstruct an employer's internal facts

Do not store actual employer/client documents, names, screenshots, tickets, exports, architecture, schemas, queries, code, production data, meeting notes, customer information, credentials, or decisions here. Record citations to public sources when used; keep proprietary evidence exclusively in approved systems.
