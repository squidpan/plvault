## Scope

The standards apply to the following requirement artifact types:

- Epic
- Feature
- Story
- Acceptance Criteria
- Business Rule
- Review

Supporting diagrams and diagram guides remain governed by their existing conventions unless explicitly incorporated into a future standard.

## EFK Candidate

After implementation and validation, the complete requirements standards increment—including metadata, document structure, repository consistency, and verification findings—should be evaluated for handoff to EFK as a reusable cross-project framework.
