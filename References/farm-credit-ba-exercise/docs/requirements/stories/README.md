# User Stories

## Purpose

This directory contains the User Stories that implement the business capabilities defined by Features within an Epic.

Each User Story represents a focused business capability that can be reviewed, estimated, implemented, tested, and demonstrated independently.

## Relationships

Epic
    ↓
Feature
    ↓
User Story
    ↓
Acceptance Criteria
    ↓
Business Rules
    ↓
UAT Test Cases

## Naming Convention

US-<epic>-<sequence>-<description>.md

Example:

US-E6-101-propose-new-debt-transaction.md
