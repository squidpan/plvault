# AC-E6-205 Book Planned Issuance

## Acceptance Criteria

### AC-205.1 Prerequisite Validation

Given a planned issuance,

When booking is requested,

Then the issuance window must be validated, funding capacity must be reserved, and a unique security identifier must be assigned.

---

### AC-205.2 Successful Booking

Given all booking prerequisites are satisfied,

When the planned issuance is booked,

Then the system creates the official issuance record and assigns it a booked status.

---

### AC-205.3 Incomplete Prerequisites

Given one or more booking prerequisites are incomplete,

When booking is attempted,

Then the booking is rejected and the missing prerequisite is identified.

---

### AC-205.4 Booking Audit Information

Given a planned issuance is successfully booked,

When the booking record is created,

Then the system records the booking date and time and the user or process that completed the booking.

---

### AC-205.5 Downstream Availability

Given a planned issuance has been booked,

When downstream processing begins,

Then the booked issuance record is available for execution and allocation activities.
