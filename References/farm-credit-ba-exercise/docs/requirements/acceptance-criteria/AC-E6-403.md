# AC-E6-403 Submit and Monitor Settlement

## Acceptance Criteria

### AC-403.1 Ready Instruction Required

Given a settlement instruction has passed all required validation,

When the Settlement Operations Analyst submits the instruction,

Then the system allows submission to the applicable settlement participant or system.

---

### AC-403.2 Incomplete Instruction Rejection

Given a settlement instruction is not marked ready for submission,

When submission is attempted,

Then the system prevents submission,

And identifies the validation conditions that remain unresolved.

---

### AC-403.3 Submission Date and Time

Given a settlement instruction is successfully submitted,

When the submission is recorded,

Then the system preserves the submission date and time.

---

### AC-403.4 Submission Actor

Given a settlement instruction is successfully submitted,

When the submission is recorded,

Then the system preserves the submitting user or system actor.

---

### AC-403.5 Submission Acknowledgement

Given a settlement instruction has been submitted,

When an acknowledgement is received,

Then the system records the acknowledgement status and receipt date and time.

---

### AC-403.6 Submission Rejection

Given a submitted settlement instruction is rejected,

When the rejection response is received,

Then the system records the rejection status and reason,

And routes the instruction for exception resolution.

---

### AC-403.7 Settlement Status Monitoring

Given a settlement instruction is in processing,

When a new status is received,

Then the system updates the current status,

And preserves the prior status in the settlement history.

---

### AC-403.8 Delayed or Unmatched Instruction

Given a settlement instruction remains delayed or unmatched beyond an applicable processing threshold,

When monitoring identifies the condition,

Then the system flags the instruction as an exception,

And makes it available for investigation.

---

### AC-403.9 Successful Settlement Status

Given securities and cash processing have completed successfully for an instruction,

When the final status is received,

Then the system records the instruction as settled.

---

### AC-403.10 Issuance Monitoring Summary

Given multiple settlement instructions exist for an issuance,

When the analyst reviews settlement progress,

Then the system displays the status of each instruction and the overall issuance settlement status.
