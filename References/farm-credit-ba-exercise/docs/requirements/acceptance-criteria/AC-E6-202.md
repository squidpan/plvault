# AC-E6-202 Validate Issuance Window

## Acceptance Criteria

### AC-202.1 Valid Funding Day

Given a scheduled issuance,

When validation is performed,

Then the issuance date must be an authorized funding day.

---

### AC-202.2 Operational Conflict Detection

Given a scheduled issuance,

When another planned issuance conflicts with the proposed issuance window,

Then the system rejects the schedule and identifies the conflict.

---

### AC-202.3 Successful Validation

Given all validation rules pass,

When validation completes,

Then the transaction becomes eligible for funding capacity reservation.
