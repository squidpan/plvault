# AC-E6-201 Schedule Issuance

## Acceptance Criteria

### AC-201.1 Approved Transaction Selection

Given an approved debt transaction is available,

When the Issuance Officer begins scheduling,

Then the officer can select the approved transaction for issuance scheduling.

---

### AC-201.2 Required Scheduling Information

Given an approved debt transaction has been selected,

When the Issuance Officer enters the proposed issuance schedule,

Then the schedule must include the proposed issuance date, expected settlement date, security type, planned issuance amount, maturity information, and responsible business area.

---

### AC-201.3 Missing Required Information

Given one or more required scheduling fields are missing,

When the Issuance Officer attempts to save the schedule,

Then the schedule is not submitted for validation and the missing information is identified.

---

### AC-201.4 Successful Scheduling

Given all required scheduling information is present,

When the Issuance Officer saves the proposed issuance,

Then the system creates a preliminary issuance schedule associated with the approved debt transaction.

---

### AC-201.5 Eligibility for Window Validation

Given the proposed issuance has been successfully scheduled,

When scheduling completes,

Then the issuance becomes eligible for issuance-window validation.
