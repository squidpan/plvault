# AC-E6-303 Allocate Securities

## Acceptance Criteria

### AC-303.1 Accepted Orders Available

Given dealer order submission has completed,

When allocation processing begins,

Then only accepted dealer orders are available for allocation.

---

### AC-303.2 Allocation Does Not Exceed Issuance

Given an executed issuance quantity,

When securities are allocated,

Then the total allocated quantity shall not exceed the executed issuance quantity.

---

### AC-303.3 Dealer Allocation Recording

Given allocation processing has completed,

When allocation results are recorded,

Then each accepted dealer order shall contain its allocated quantity.

---

### AC-303.4 Allocation Traceability

Given allocations have been completed,

When allocation records are reviewed,

Then each allocation shall be traceable to both the executed issuance and the originating dealer order.

---

### AC-303.5 Unallocated Quantity

Given the executed issuance is not fully allocated,

When allocation processing completes,

Then any remaining unallocated quantity shall be recorded.

---

### AC-303.6 Allocation Completion

Given allocation processing has completed,

When all allocation validations succeed,

Then the allocation results become available for execution-result recording.

---

### AC-303.7 Allocation Audit

Given allocation processing has completed,

When allocation records are stored,

Then the allocation date, time, and responsible user or process shall be preserved.
