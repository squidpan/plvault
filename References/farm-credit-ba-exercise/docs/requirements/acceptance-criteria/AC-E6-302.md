# AC-E6-302 Receive Dealer Orders

## Acceptance Criteria

### AC-302.1 Executed Issuance Required

Given an issuance has been successfully executed,

When dealer order submission begins,

Then the issuance is available to receive dealer orders.

---

### AC-302.2 Authorized Dealer Submission

Given a dealer is authorized to participate,

And the issuance is open for order submission,

When the dealer submits an order,

Then the order is accepted for validation.

---

### AC-302.3 Required Order Details

Given an authorized dealer submits an order,

When the order is validated,

Then the order must include the participating dealer, requested quantity, issuance identifier, and submission time.

---

### AC-302.4 Order Submission Window

Given an issuance has an authorized order submission window,

When a dealer submits an order during that window,

Then the order is eligible for acceptance.

---

### AC-302.5 Late Order Rejection

Given the authorized order submission window has closed,

When a dealer submits an order,

Then the order is rejected,

And the rejection reason is recorded.

---

### AC-302.6 Unauthorized Dealer Rejection

Given a dealer is not authorized to participate in the issuance,

When the dealer submits an order,

Then the order is rejected,

And the rejection reason is recorded.

---

### AC-302.7 Accepted Order Preservation

Given a dealer order has passed validation,

When the order is accepted,

Then the order details and submission time are preserved.

---

### AC-302.8 Allocation Availability

Given one or more dealer orders have been accepted,

When the order submission process is complete,

Then the accepted orders are available for allocation processing.
