# AC-E6-402 Create Settlement Instructions

## Acceptance Criteria

### AC-402.1 Confirmed Transaction Required

Given a dealer transaction has been confirmed,

When settlement-instruction creation begins,

Then the transaction is eligible for settlement-instruction generation.

---

### AC-402.2 Required Instruction Information

Given a confirmed dealer transaction is eligible for settlement,

When the settlement instruction is created,

Then the instruction includes the required parties, accounts, security identifier, quantity, settlement date, amount, currency, and settlement method.

---

### AC-402.3 Unique Instruction Identifier

Given a settlement instruction is created,

When the instruction is saved,

Then the system assigns a unique settlement-instruction identifier.

---

### AC-402.4 Successful Instruction Validation

Given a settlement instruction contains complete and valid information,

When the instruction is validated,

Then the system marks the instruction ready for submission.

---

### AC-402.5 Missing Settlement Account

Given a required securities or cash account is missing,

When the instruction is validated,

Then the system prevents the instruction from being marked ready,

And identifies the missing account information.

---

### AC-402.6 Invalid Settlement Date

Given the settlement date is invalid or unavailable,

When the instruction is validated,

Then the system rejects the instruction,

And records the validation reason.

---

### AC-402.7 Settlement Amount Reconciliation

Given a settlement instruction has been generated,

When the settlement amount is validated,

Then the quantity, price, principal, accrued interest when applicable, and total amount agree with the confirmed dealer transaction.

---

### AC-402.8 Duplicate Instruction Prevention

Given an active settlement instruction already exists for the dealer transaction,

When another instruction is created,

Then the system prevents creation of an unintended duplicate.

---

### AC-402.9 Ready for Submission

Given all required settlement instructions have passed validation,

When instruction creation is complete,

Then the issuance is marked ready for settlement submission.
