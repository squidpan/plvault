# AC-E6-404 Resolve Settlement Exceptions

## Acceptance Criteria

### AC-404.1 Exception Identification

Given a settlement instruction is rejected, unmatched, delayed, or failed,

When the condition is received or detected,

Then the system creates or updates a settlement exception record.

---

### AC-404.2 Exception Classification

Given a settlement exception exists,

When the Settlement Operations Analyst reviews it,

Then the analyst can classify the exception by type and severity.

---

### AC-404.3 Required Exception Details

Given an exception is recorded,

When the exception record is saved,

Then it includes the affected instruction, current status, reason, source, date and time, and responsible party when known.

---

### AC-404.4 Investigation History

Given an exception is under investigation,

When the analyst records findings or actions,

Then the system preserves the investigation notes, user, and date and time.

---

### AC-404.5 Authorized Correction

Given an operational data correction is required,

When an authorized analyst applies the correction,

Then the system records the original value, corrected value, reason, user, and date and time.

---

### AC-404.6 Corrected Instruction Resubmission

Given a settlement instruction has been corrected and validated,

When the analyst resubmits it,

Then the system creates a traceable resubmission attempt,

And retains the prior submission and rejection history.

---

### AC-404.7 Unresolved Exception Blocking

Given a blocking settlement exception remains unresolved,

When settlement completion is attempted,

Then the system prevents the issuance from being marked settled.

---

### AC-404.8 Successful Exception Resolution

Given the cause of an exception has been corrected and the affected instruction has reached an acceptable status,

When the analyst resolves the exception,

Then the system records the exception as resolved.

---

### AC-404.9 Resolution Audit Information

Given an exception is resolved,

When the resolution is recorded,

Then the system preserves the resolution reason, resolving user, and resolution date and time.

---

### AC-404.10 Ready for Settlement Completion

Given all blocking settlement exceptions for the issuance have been resolved,

When exception processing is complete,

Then the issuance becomes eligible for final settlement-completion verification.
