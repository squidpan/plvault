# AC-E6-301 Execute Issuance

## Acceptance Criteria

### AC-301.1 Eligible Booked Issuance

Given a planned issuance has been booked,

And the issuance has a valid security identifier,

When the Issuance Officer requests execution,

Then the issuance is identified as eligible for execution.

---

### AC-301.2 Successful Execution

Given the booked issuance is eligible for execution,

When the Issuance Officer executes the issuance,

Then the system records the issuance as executed.

---

### AC-301.3 Execution Date and Time

Given an issuance has been successfully executed,

When the execution event is recorded,

Then the execution date and time are preserved.

---

### AC-301.4 Execution Actor

Given an issuance has been successfully executed,

When the execution event is recorded,

Then the authorized user or process responsible for execution is preserved.

---

### AC-301.5 Ineligible Issuance Rejection

Given an issuance is not booked or does not have a valid security identifier,

When execution is requested,

Then the system rejects the execution request,

And records the reason the issuance was not eligible.

---

### AC-301.6 Dealer Participation Availability

Given the issuance has been successfully executed,

When execution processing is complete,

Then the issuance becomes available for dealer participation and order capture.

---

### AC-301.7 Duplicate Execution Prevention

Given an issuance has already been executed,

When another execution request is submitted,

Then the system prevents duplicate execution,

And preserves the original execution record.
