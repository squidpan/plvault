# AC-E6-401 Confirm Dealer Transactions

## Acceptance Criteria

### AC-401.1 Retrieve Finalized Dealer Transactions

Given issuance execution and allocation are complete,

When the Settlement Operations Analyst opens the issuance for confirmation,

Then the system displays all finalized dealer transactions associated with the issuance.

---

### AC-401.2 Confirm Required Transaction Information

Given a dealer transaction is available for confirmation,

When the analyst reviews the transaction,

Then the transaction includes the required dealer, security, quantity, price, date, amount, and settlement-party information.

---

### AC-401.3 Successful Transaction Confirmation

Given a dealer transaction contains complete and valid information,

When the analyst confirms the transaction,

Then the system records the transaction as confirmed.

---

### AC-401.4 Confirmation Audit Information

Given a dealer transaction has been confirmed,

When the confirmation is recorded,

Then the system preserves the confirming user and confirmation date and time.

---

### AC-401.5 Missing Required Information

Given a dealer transaction is missing required information,

When confirmation is attempted,

Then the system prevents confirmation,

And identifies the missing information.

---

### AC-401.6 Inconsistent Execution or Allocation Information

Given dealer transaction information does not agree with the finalized execution or allocation record,

When the analyst reviews the transaction,

Then the system prevents confirmation,

And records the discrepancy for correction.

---

### AC-401.7 Invalid Settlement-Party Information

Given a dealer settlement party or account is invalid or inactive,

When the transaction is validated,

Then the system prevents confirmation,

And places the transaction in an exception or pending-correction status.

---

### AC-401.8 Ready for Settlement Instructions

Given all required dealer transactions have been confirmed,

When confirmation processing is complete,

Then the issuance is marked ready for settlement-instruction creation.
