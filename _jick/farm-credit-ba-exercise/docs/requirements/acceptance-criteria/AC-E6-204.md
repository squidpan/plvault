# AC-E6-204 Assign Security Identifier

## Acceptance Criteria

### AC-204.1 Identifier Assignment

Given a planned issuance with reserved funding capacity,

When security identifier assignment is requested,

Then the system assigns a security identifier to the planned issuance.

---

### AC-204.2 Identifier Uniqueness

Given a proposed security identifier,

When the identifier is validated,

Then the identifier must not already be assigned to another security.

---

### AC-204.3 Duplicate Identifier Rejection

Given a proposed security identifier that is already in use,

When assignment is attempted,

Then the assignment is rejected and the duplicate identifier condition is recorded.

---

### AC-204.4 Assignment Complete

Given a unique security identifier has been assigned,

When assignment processing completes,

Then the planned issuance becomes eligible for booking.
